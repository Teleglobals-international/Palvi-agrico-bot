## WHAT IT TAKES TO RUN IT

→ **A farmer/customer database** — Phone numbers and basic crop/purchase info loaded into the system.

→ **Telephony integration connected once** — Exotel or Twilio set up one time. No manual dialing after that.

→ **Regional language STT/TTS configured** — Sarvam AI (or equivalent) handles speech in local dialect. Setup once, runs forever.

→ **Call scripts defined** — Business team defines the script (offer, product pitch, FAQ). Bot follows it with zero drift.

→ **LLM fallback for edge cases** — Claude handles unexpected farmer questions so the bot never gets stuck.

---

## WHO IT'S FOR

✔ **Agri-input companies doing outbound sales calls**
Replaces a 10-person telecalling team. Bot calls 1,000 farmers/day with consistent pitch, zero fatigue.

✔ **Not a replacement for field sales**
The bot qualifies leads, pitches offers, and collects orders. Field reps close complex deals.

✔ **Promotional campaign execution**
Lucky draws, seasonal offers, new product launches — one script change, thousands of calls.
